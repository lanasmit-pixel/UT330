Building this site

September 9, 2026 · Week 1

This was my first class assignment. I set up my repository, connected it to GitHub Pages, and started customizing the website to make it feel more like my own.

What I changed

I kept the basic HTML structure but changed the styling in custom.css. I wanted the website to have a cute and simple look, so I changed the colors to light pink and white and added pink details throughout the site.

I also changed the font to Quicksand because I wanted something softer and more playful than the original font. I changed the headings, links, buttons, borders, and other elements so that the different pages would feel more connected.

On my About page, I added a personal photo and created a pink frame around it. I also used CSS to place my photo next to my About Me text instead of having everything stacked vertically.

What I learned

One of the biggest things I learned was how much you can change with CSS without changing the basic HTML structure. I was able to change the colors, fonts, spacing, image size, and layout just by adding my own CSS.

I also learned more about how classes work. For example, I used .about-photo to control the size and pink border of my photo and .about-me to control how my photo and text sit next to each other.

What I want to change next

I want to keep making the site feel more personal as the semester goes on. I would like to add more small design details and continue experimenting with the layout while keeping the website easy to navigate.
